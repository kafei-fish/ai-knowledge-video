# 脚本公式与样例

## 一条片子的结构

| 段落 | 时长（推理类） | 要做到什么 | 常见错误 |
| --- | --- | --- | --- |
| 合集片头 | 1–2 秒 | 先出合集名，再出本期概念名 | 片头太长，观众直接划走 |
| 强开场 | 3–5 秒 | 一个反直觉的问题或冲突场面 | 用"大家好，今天讲"开头 |
| 场景 | 15–25 秒 | 把概念放进一个具体故事 | 一上来就下定义 |
| 揭示 | 20–40 秒 | 讲清为什么会这样，只讲一个点 | 一条里塞两三个概念 |
| 现实映射 | 8–12 秒 | 两三个生活里的例子快切 | 例子太多，变成清单 |
| 升华结尾 | 8–12 秒 | 从故事跳到人生或社会层面的一句话 | 喊关注、抛投票问题 |

情绪类（竖屏，30–45 秒）去掉"揭示"，改成"一道算术题"或"一个反转事实"，结尾给一个具体行动。

## 写法规则

- 每句 ≤20 字，口语，能一口气读完
- 用 | 分隔字幕行，一行就是屏幕上的一行字幕
- 全文切成 3–4 段写进 script.json（段号 p1、p2…），每段 15–25 秒，分段配音，出错只重做一段
- 想加重的词用【】包起来，字幕会变成金色
- 数字写成汉字（"九十七枚"），配音读得准
- 推理类每秒约 4.5 字，80 秒约 360 字
- 不出现"评论区""点赞""关注"
- 人名、年份、实验、数据都要能查到出处，查不到的删掉

## 标题规则

- ≤20 字（抖音标题太长会被折叠）
- 写结论或冲突，不写概念名："两个聪明人，为什么一起坐牢"好过"什么是囚徒困境"
- 概念名放进合集名和话题标签

## 样例一：博弈论 EP.04 · 智猪博弈（横屏，79 秒，已发布）

第一段（强开场 + 场景）：
猪圈里有一大一小两头猪。|一头有个踏板，|踩一下，另一头的食槽就掉下十份食物。|可踩完再跑回来，|要消耗两份的体力。|等踩的那头猪跑回来，|另一头早就开吃了。|问题来了：|谁去踩？

第二段（揭示，配 2×2 收益矩阵逐格亮起）：
先看小猪。|如果大猪去踩，|小猪守在槽边能先吃四份；|跟着一起去踩，|扣掉体力只剩一份。|如果大猪不动，|小猪自己去踩，|跑回来只抢到一份，|反而亏掉一份。|所以不管大猪怎么做，|小猪的最优解都是：|等。|小猪一定不动，|大猪就只剩一个选择：|自己去踩，|吃到六份，|扣掉体力净赚四份。|不踩，|就一口都没有。

第三段（现实映射 + 升华）：
结局是：|大猪跑前跑后，|小猪躺着等饭，|净收益一模一样。|这就是智猪博弈。|现实里到处都是：|大品牌花钱教育市场，|小品牌跟着卖；|小组作业里，|总有人等着别人做完。|小猪不是懒，|它只是看清了自己的位置。|弱者的聪明，是找准时机；|强者的担当，是先迈出那一步。

封面：博弈论 · EP.04 / 智猪博弈 / 大猪干活，小猪躺赢

## 样例二：人生刻度 · 02 · 和父母的时间（竖屏，40 秒，已发布）

假如你今年二十五岁，|父母五十岁。|他们还能陪你多久？|如果他们活到八十岁，|还有三十年，一万多天。|听起来很长。
可你在外地工作，|每年只有过年、国庆回家，|加起来大约十天。|三十年，每年十天。|你和父母剩下的相处时间，|只有三百天。|不到一年。
这道题最残忍的地方，|不是数字小，|而是它每过一年，就少十天。|这个周末，给他们打个电话吧。|下次回家，把手机放下。

封面：人生刻度 · 02 / 和父母的时间 / 你和父母，这辈子只剩不到一年
